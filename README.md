# prayer_app

Android app (Java) showing daily zmanim, prayer times and the Hebrew date, with Firebase login.

## Build

1. Open the project in Android Studio.
2. Add your own Firebase config as `app/google-services.json` (Firebase console → Project settings → Your apps).
3. Run the `app` configuration, or `./gradlew assembleDebug`.

## Credentials

OAuth client secrets, keystores and `.env` files are git-ignored and must never be committed.
Keep local copies outside the repo.
